RootsVoice 2.2.3 - by nightfellas
=================================

FIRST TIME (once per computer, needs internet)
  Double-click  setup_rootsvoice.bat
  It installs everything RootsVoice needs - Python 3.11 if needed, the
  speech engine (faster-whisper), the other components, the speech model -
  and puts a "RootsVoice" shortcut on your desktop. Takes 5-15 minutes.
  If Windows asks for permission, click Yes.

EVERY TIME AFTER THAT
  Use the RootsVoice desktop shortcut, or double-click RootsVoice.bat.

IF SOMETHING IS MISSING LATER
  RootsVoice tells you at startup and offers "Install now".
  It is also under Help (the ? button) > Install missing components.
  Help > Check setup confirms the microphone, speech engine and
  projection software are ready.

Keep these files together in one folder:
  rootsvoice.py, requirements.txt, setup_rootsvoice.bat, RootsVoice.bat, assets\roots.ico
